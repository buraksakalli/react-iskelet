Custom Dimensions with Numbers (px)

Skeleton components with custom pixel dimensions using number values

<Skeleton type="text" width={400} height={20} />
<Skeleton type="title" width={250} height={30} />
<Skeleton type="avatar" width={80} height={80} />
<Skeleton type="thumbnail" width={120} height={150} />

Custom Dimensions with CSS Values

Skeleton components with custom CSS string dimensions

<Skeleton type="text" width="75%" height="1rem" />
<Skeleton type="title" width="50%" height="1.5rem" />
<Skeleton type="avatar" width="5rem" height="5rem" />
<Skeleton type="thumbnail" width="8rem" height="10rem" />

Multiple Items with Custom Dimensions

Using the count prop with custom dimensions

<Skeleton type="text" count={3} width="90%" height="0.8rem" />
<Skeleton type="avatar" count={2} width={60} height={60} />

Partial Customization

Customizing only width or height while keeping the other dimension default

<Skeleton type="title" width="75%" />
<Skeleton type="avatar" height={100} />
